# 抖音成片脚本 ·《故宫屋顶那只长翅膀的猴子》

**格式**：冷知识前置式（内容价值在前，App 展示在后）  
**总时长**：约 50 秒  
**画幅**：竖屏 9:16（1080×1920）  
**核心钩子**：为什么全国只有太和殿有 10 只脊兽？第 10 只长得像插翅猴子。  
**素材来源**：你小程序内的脊兽金色抠图、头图、首页北京插画、内容页截图（均为自有素材，可商用）

## BGM 与音效建议

- **BGM**：前半段用「国风悬疑/轻快鼓点」（如剪映素材"古风悬疑""探秘"），第 4 镜揭秘处转"顿悟感"音效，后段切「治愈国风」（盖章、集章部分），整体不超过 -18dB，不压人声。
- **音效**：脊兽点亮"叮"、第 10 只揭示"唰"、盖章"咔"（重音，情绪锚点）、成就页"叮咚"升级音。
- **人声**：干声 + 轻微混响，语速偏快、像朋友讲秘密，别播音腔。

## 拍摄 / 制作备注

1. **素材清单**：脊兽 10 只抠图（自有）、故宫头图/屋檐特写（建议用你自己小程序内素材或自拍，避免直接搬运网络图引发版权/限流）、首页北京插画、内容页截图、盖章动效。
2. **录屏原则**：App 画面只在第 5、6 镜出现，且是"点一下/盖一章"的短动作，不要把录屏当主内容。
3. **字幕**：全部用大字号、高对比（白字+描边或深色底），抖音默认静音播放，字幕必须能独立传达信息。
4. **前 3 秒**：镜 1 决定划走率，务必用"反常识画面 + 一句话悬念"，不要开头就放 Logo/自我介绍。

### 复用说明

这条模板可**套用到每一座城市**：钩子换成该城地标的反常识冷知识 → 切该城手绘插画 → 点地标 → 内容页 → 盖章 → 集章成就。你"每座城市一套"的模式，天然适合做成**连载系列**（"城市冷知识·第 N 城"），用合集沉淀粉丝。
